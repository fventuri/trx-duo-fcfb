# Contributing

Thank you for your interest in this project. Contributions are welcome — through
issues, not pull requests.

## Pull requests are not accepted

To keep the quality and style of the code consistent, **pull requests to this
repository are not accepted and will be closed.** Please do not open a PR.

## Instead, open an issue

For any bug, change, or improvement:

1. **Open a new issue** describing the problem (or the change/improvement you have
   in mind) and, if you have one, the solution you would suggest.
2. **We discuss it together** in the issue.
3. **We implement it** and it lands through the project's normal release process.

This keeps every change traceable and reviewed before it becomes part of the code.

## Using AI assistants is fine

It is perfectly OK to use AI assistants when preparing an issue. In particular,
you are welcome to:

- use an AI assistant to help **write the issue**;
- **include code snippets** in the issue (for example, a proposed patch, a
  reproduction, or a sketch of the fix);
- **reference a forked repository and its development branch**, so we can look at
  the code you have in mind.

Whatever helps describe the problem and the proposed solution clearly is welcome.
